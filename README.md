# IT Audit Risk Analyzer

## Overview

A personal project that simulates an IT audit
using fictional employee, access and transaction data.

## Objective

Identify potential control risks involving:

- inactive accounts;
- excessive privileges;
- segregation of duties;
- unusual transactions.

## Technologies

Python
Pandas
SQL

## Current Status

MVP completed.

Future improvements:
- Power BI dashboard;
- automated reporting;
- additional control tests;
- risk scoring.
